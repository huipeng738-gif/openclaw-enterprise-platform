# 默认草稿结构

用户有模板或格式要求时，以用户要求为准。下面的结构用于无模板时起草，不要求填满所有章节。

## 制度说明

- 标题及适用对象
- 核心规定与适用条件
- 办理流程或执行步骤
- 例外及注意事项
- 依据来源
- 待确认事项（如版本、生效日期或责任人缺失）

现有制度说明应基于资料解释；拟定新制度时，标题明确标注“建议稿”，新增条款明确标为建议。

## 业务报告

- 标题、报告范围及期间
- 摘要
- 已知事实与资料依据
- 分析判断（标明推断）
- 建议与后续行动
- 来源及待补充数据

没有真实经营数据时，仅交付资料总结或待填报告框架，不生成虚构趋势、金额或同比数据。

## 工作方案

- 背景与目标
- 范围和交付物
- 建议实施步骤
- 责任分工及时间安排（未知时标为待确认）
- 依赖、风险与验收条件
- 来源及待确认事项

方案中的时间、人员和预算未被用户确认时属于建议，不视为执行授权。
